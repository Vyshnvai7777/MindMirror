    The 4-Step Prediction Process

    1

    Text Feature Extraction — Your text is analysed for word choice, sentence structure, emotional language, abstract vs concrete thinking, and social references.

    2

    MBTI Pattern Matching — Features are compared against real linguistic patterns from 8,675 typed profiles across all 16 personality types.

    3

    4-Dimension Scoring — Each MBTI axis (E/I, S/N, T/F, J/P) is scored independently using NLP pattern analysis.

    4

    Confidence Breakdown — You receive a confidence score per dimension plus the final predicted type and closest alternatives.

    ⚠️ Note: This prediction is for self-discovery only. For a deeper assessment, take the full 30-question quiz. MBTI is a psychological framework and no text analysis can definitively determine personality type.

    📦 MBTI Kaggle Dataset

    The model uses the Myers-Briggs Type Indicator dataset by datasnaek on Kaggle, containing 8,675 users with their MBTI type and their last 50 forum posts (separated by |||). This provides real linguistic patterns for all 16 personality types.
